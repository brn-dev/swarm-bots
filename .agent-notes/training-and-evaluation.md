# Training and evaluation maintenance

Read [AGENT_NOTES.md](../AGENT_NOTES.md) first. Learning paths below are relative to `swarmbots/learn`.

- Accepted review decisions (explicitly confirmed by the owner): the replay memory footprint, progress rewards with potential discount 1.0 versus learner gamma 0.995, default-enabled NOP, and evaluation on the existing morphology pool are all intentional and acceptable. Do not repeat these as findings, caveats, or requests for ablations in future reviews. Revisit only for a new concrete defect, changed requirements, or an explicit question about that choice; lack of convergence experiments alone is not a new issue.
- PPO/off-policy rollout-device changes move environment wrappers, cached observations, recurrent histories and exploration noise together. gSDE noise is a nonpersistent buffer: module device moves include it, checkpoints omit it.
- Retain the short MAT/RMAT rollout default: project experiments found significantly worse MAT performance with longer sequences and fewer parallel environments. That comparison changes both temporal horizon and parallelism; it does not isolate sequence length.
- Training is intended for high CUDA parallelism, with 1,024 worlds as the standard starting workload. For fractional off-policy update counts caused by too few environments, recommend increasing `num_envs` to a compatible count. Do not recommend lengthening collection to accommodate tiny training workloads; small CPU examples are execution/debugging checks.
- SAME_STEP returns reset observations; terminals are `final_obs` selected by `_final_obs`. Truncation bootstrap uses terminals; recurrent PPO requires TBPTT. Observation buffers are reused: retained data needs copies; integer-indexed reset writes must assign back to source tensors.
- `base_policy.policy_inference_step` brackets complete PPO/MAPPO/MAT/RMAT CUDA graph inference and recurrent SAC/TD3 `act_with_temporal_state`, snapshotting actions/states before subsequent policy or wrapper calls reuse storage. Boundaries stay outside compiled submodules; apply them only to public inference, never gradient-bearing sequence-training calls.
- PPO's shared step collector feeds both dense-batch and episode-segment storage; keep policy/noise/step/bootstrap logic there. Core-policy validation rejects dropout and randomized RReLU because eval/train mode changes invalidate rollout likelihoods; deterministic RReLU is allowed and NOP stochastic layers are independent. Entropy regularization belongs to learners: PPO's masked joint-importance-weighted `mc_ent_coef`, SAC temperature tuning. SAC needs pathwise/straight-through sampling; ordinary SMB is for PPO, Gumbel SMB for SAC. Squashed Gaussian likelihoods use stable pre-tanh Jacobians.
- `rollout_utils.collect_rollout_step_metadata` validates episode/final masks and supplies completed indices and bootstrap decisions from one host transfer. Reuse it in PPO stats/bootstrap paths; tensor terminal selection uses `where` instead of CUDA row compaction. Validate complete tensor-dictionary terminal shapes from metadata first: broadcasting can silently mix environment and agent axes. Recurrent replay candidate filtering already guarantees temporal checkpoints, so its private checkpoint gather must not repeat a synchronizing value check.
- `action_dists/gsde_noise.py` lazily imports the selective CUDA kernel in `_gsde_noise_triton.py`. Keep its Triton imports at module scope: supported Triton 3.2/3.3 do not capture Python closures. The kernel supports strided storage. Torch owns its seed/current stream, preserving manual seeding and evaluation RNG isolation while changing exact samples versus the old sampler. No-grad CUDA resets avoid host mask reads; CPU, missing Triton and grad-enabled resets share compact Torch draws for selected rows only. Flatten only contiguous noise in that fallback: reshaping strided storage can copy and lose writes. Reject nonempty writes to inference-owned noise outside inference mode before any mutation. Raw kernel writes must increment Torch's version. Gradient-bearing gSDE samples snapshot noise only when standard-deviation gradients need it, protecting pending graphs across resets/state swaps without copies in rollout/evaluation. Avoid state-sharing flags: restored tensors can alias old generations, and conservative copying would allocate full noise on every adapter call.
- Segmented PPO batches host metadata transfers and groups partial episodes by length for GAE. Preserve lane order, initial histories and independently retained advantage/return storage; observation views with `clone_tensors=False` remain intentional. Per-lane scalar reads and GAE loops make CUDA finalization scale poorly with world count.
- PPO evaluates successor critics only for truncations or unfinished rollout boundaries. Keep full critic batch shapes for compiled policies; combine bootstrap/autoreset decisions into the existing host transfer instead of adding synchronization. The last recurrent step supplies both terminal and ongoing final values. Checkpoint loading clears PPO's live rollout cache/buffer, because normalization and weights can rewind independently of cached observations/history.
- Diagnostics need masks from their own cached parameter batch, captured before replay updates replace it. Exclude recurrent padding/unused truncation successor slots. NOP metrics stay detached on-device until aggregation; reusable compiled outputs need snapshots.
- PPO training requests deferred loss metrics; direct loss calls materialize by default. `TensorSummaryStatistics` retains shape-derived integer counts separately from mean/std/min/max, and `MetricsLists` snapshots and batches scalar/moment transfers by device/dtype before sample-weighted aggregation. Mask compaction still synchronizes CUDA once; dense masked reductions were slower in eager measurements. Episode-info extraction batches completed rows by device/dtype and retains per-field presence masks.
- `optimizers.py` selects fused Adam for CUDA training and ordinary Adam elsewhere. PPO/off-policy clipping and read-only policy gradient diagnostics share float64 foreach norm accumulation: finite gradients can overflow float32 norms. Diagnostics use `max_norm=None` and materialize one float per group. PPO requests non-finite rejection before scaling, retaining its existing CUDA host check; the off-policy default avoids gradient-value reads and CPU synchronization. Keep the clipping scalar in the gradients' computation dtype so foreach multiplication stays fast. Optimizer restoration reselects execution settings for the destination device and clears CUDA capture flags on CPU; fused step counters stay on the accelerator, ordinary non-capturable counters stay on CPU.
- NOP gradient-norm totals must include the wrapped policy and auxiliary parameters exactly once; component groups can overlap.
- SAC tests derive optimizer ownership from concrete modules, not parameter accessors. Check mean/std/Q readouts separately from encoders and NOP. Isolate Q-to-actor learning with entropy/NOP disabled for single/multiple samples; isolate NOP source gradients, including retained cached features and branch separation. Compare target tensors with Polyak interpolation: aggregate parameter movement or call counts can hide disconnected learning objectives.
- TD3/SAC delays use persistent update counters; SAC delay also gates temperature. Critic NOP updates each step, actor NOP follows actor delay. `algos/off_policy/recurrent.py` owns shared recurrent NOP preparation and backward/clip/step mechanics; TD3 can supply actor latents later on delayed updates. Recurrent TD3 preserves separate online/target actor histories; critics consume matching detached states. Candidate-action branches must not overwrite executed-action history.
- `presets/off_policy.py` owns shared high-level SAC/DDPG/TD3 optimization and recurrent replay defaults. `make_training` uses a fixed 1,024-position batch budget, converting recurrent batches to whole sequences after horizon overrides. Explicit `batch_size` overrides count sequences for recurrent learners and transitions otherwise; burn-in is outside the scored-position budget. Replay capacity uses one common rule with a recurrent segment-storage minimum. Constructor `replay_exposure` replaces fixed gradient counts; updates per collection cycle must be a positive integer, with no rounding, accumulation or checkpoint credit. High-level construction validates this before allocating environments; recurrent accounting excludes burn-in. Low-level omitted collection lengths use one vector step; never extend collection to fit replay batches. Registered presets use exposure 8 and gamma 0.995; low-level learner constructors retain independent defaults.
- Recurrent off-policy replay permits at most one truncation in the scored learning suffix, with no such limit in burn-in. `make_training` rejects `episode_length < learning_steps` before allocating environments; low-level recurrent learners also validate known episode limits. Genuine terminations do not count toward this restriction.
- Replay terminal observation cleanup relies on host-only per-transition-slot presence flags. Maintain them when allocating/freeing terminal rows and resetting replay; checking the CUDA index tensor to discover an empty slot restores a per-insertion synchronization.
- Off-policy normalization accepts one observation wrapper per key, including empty/disjoint feature selections and wrappers separated by transition history. Duplicate-key validation happens before changing observation/reward output flags; on-policy composition is unchanged.
- Off-policy `normalization.py` configures observation/reward wrappers to emit raw data while updating statistics. Replay, terminal observations, cached rollout observations and transition history remain raw. The collector normalizes public policy inputs; `train` snapshots current statistics once, normalizes sampled current/next observations, burn-in and NOP windows, then reuses normalized NOP origin views. Never normalize replay storage or update statistics during sampling. Recurrent stored states remain approximate under weight/statistics drift; existing burn-in reduces that mismatch. Off-policy benchmark/frozen evaluators assemble raw transition history before applying their evaluation snapshot, including raw-zero reset sentinels; on-policy wrapper ordering is unchanged. CUDA normalization compiles by default; an explicit `compile_tensor_operations=False` on any participating observation wrapper keeps that fused pass eager. Compiled normalization outputs must survive backward and policy CUDA-graph boundaries, so these transforms disable CUDA graphs. Separate wrapper statistics-only/normalizing entry points avoid sharing Dynamo's compile budget.
- `train` saves/closes; `make_training` leaves closing to the caller. Example scripts require fresh output directories; Python supports continuation. `total_timesteps` is an absolute final counter. Both helpers retain training seed/construction options for run metadata; metadata also records resolved environment settings and source commit/dirty-content hash before the first update. Installed packages must not attribute an enclosing application's Git revision to SwarmBots.
- `execute_command(name)` supports read-only inspections and returns success; queued names can be separated by semicolons. There are no mutation, pause/stop, save, or recording commands, subclass command overrides, or command-driven metadata/logging. Ordinary Python save/load and scheduler APIs remain.
- `presets/nop.py` shares public local/global target configuration across learners. MultiPayloadGoal scalar/rotation targets carry raw payload-active flag indices through `ObsIndices` and `NextObsPredConfig`; mask targets, bases and predictions before nonlinear losses, without treating ordinary zero-valued goals as padding. Critic MSE is averaged across Q heads before adding NOP for SAC/DDPG/TD3.
- NOP scalar/angle/rotation targets always use per-step deltas; binary targets predict next-state flags and latent transitions always add residual updates. There are no prediction-mode config fields or serialized mode settings. Aligned replay inputs already provide per-step bases; origin-only PPO/recurrent windows reconstruct bases from the origin and preceding successors. Angle `(sin, cos) = (0, 0)` denotes undefined connector twists: require both endpoints and average only defined angles. Global scalar activity masks require unreduced per-target custom losses; arbitrary per-item reductions cannot recover feature-level masking.
- Tensor-dictionary `final_obs` fields enter learning wrappers as owned terminal snapshots. Wrappers retain unchanged field identities and snapshot replaced fields, avoiding repeated full copies and CUDA mask reads; object-array terminals retain selected-row handling. Original MAT uses asynchronous CUDA prefix-mask validation instead of host scalar decisions.
- A fresh `as_benchmark_policy` per evaluation/recording owns temporal/action/noise state and freezes normalization without mutating training statistics. It shares the actor: no concurrent training. Scenario-conditioned evaluation needs explicit `scenario_id`; supplied IDs win, and public globals are padded before normalization.
- `FrozenEvaluationRunner` caches only environments with successfully configured normalization. Failed setup closes the newly created environment before propagating the error; retries must create and validate a fresh environment.
- `BasePolicy.uses_replay_normalization` declares normalization after raw history assembly. SAC/TD3 families declare it for standalone evaluation, and `OffPolicyAlgorithm` enables it for any supplied policy. Custom standalone replay policies must declare the capability too. Evaluation reads it through whole-policy `_orig_mod` compiler wrappers; inference retains the provided wrapped policy.
- `gsde_reset.reset_gsde_noise` shares noise initialization and scheduled resets across off-policy rollout, benchmark adapters and frozen evaluation. `ScheduledEvaluationHook` forwards the current trainer schedule on every evaluation; direct `FrozenEvaluationRunner.evaluate` calls require `gsde_reset_mode` for gSDE policies.
- Protocol evaluation takes the first episode per lane in lane order, requiring `num_episodes <= num_envs`. Recording recycles lanes, explicitly resets completed `NEXT_STEP` worlds before the next policy call to keep terminal observations out of policy history, discards interrupted episodes, closes environments and waits for writers. Actors may combine public observations across agents, never privileged fields. Evaluation seeds sample the existing morphology pool, not unseen morphologies.
- Logging console/persistence profiles are independent. Filtering follows aggregation; preserve scenario-success presence masks, CSV columns/history and restored compressed logs.
- Numerical diagnostics prioritize ordinary training ranges. Artificial huge/tiny floats and exact integer preservation beyond float64 precision are accepted low-priority limits. Keep basic non-finite handling; pursue broader precision work only when real workloads need it.
- The standalone PPO example stays independent of `swarmbots.learn`; stored pre-tanh samples avoid inverse-tanh saturation because squash Jacobians cancel in PPO ratios. Biasless PopArt needs its offset; zero-angle rotation gradients need analytic sinc coefficients.
