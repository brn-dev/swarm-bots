# Agent notes

Keep navigation and costly gotchas; defaults/layouts belong in source, history in CHANGELOG.md. Learning paths below are relative to `swarmbots/learn`.

## Navigation

- `swarmbots/benchmark`: construction/evaluation. `swarmbots.learn`: lazy public helpers. `presets/variants.py`: public registry; `presets/policy_factory.py`: construction/wrappers; `presets/tmasac.py`: recurrent/shared settings. `algos/off_policy/`: shared SAC/DDPG/TD3 lifecycle/components.
- Variant names use `base_variant__modifier__modifier`. Major architecture names keep single underscores (`mat_orig`, `mat_ind`, `mat_dec`, `mat_qcx`, `tmasac_dec`, `tmatd3_dec`); recurrence and other modifiers use `__` (`mat_qcx__lstm`, `masac__deepset_critic`). Superseded spellings are rejected without aliases. `tmasac__ac_shared_observation_encoder` and its `__slstm` form are low-level only; `ac` means actor/critic sharing, distinct from sharing between Q heads. Module/class/config-field names do not follow the variant naming scheme.
- `presets/model_scale.py` owns fixed, versioned layouts, never runtime fitting. Default `5M-2L NOP1M`; other choices `2.5M NOP0.75M`, `5M-3L NOP1M`, `10M NOP2M`. Small/large versions are v6/v7; 2L v1 and 3L v2. Scales describe feed-forward references: recurrence and gates add capacity, DDPG has one ordinary head. `model_scale=None` / CLI `legacy` uses current explicit widths, not historical shared MAT. Save resolved layouts/versions; depths are explicit, widths task-independent.
- `5M-2L` replaces the original `5M` layout without architecture changes; old `5M`/`5+1M` aliases are rejected. `5M-3L` varies only attention/Deep Set encoder stacks; FF-only actors, PPO/MAPPO, decoder depths, Q/V heads and NOP core retain their architectures. Three-layer encoders use narrower FFNs/tokens; 3L memory widths match complete 2L recurrent counts within 0.5% while preserving each feed-forward backbone. Gates remain additive. `ScaleLayout.slug` identifies separate audit/diagram folders; equal parameter budgets must not share paths. PPO/MAPPO are identical across the depth choices.
- The registry has 17 core presets, two hidden NOP controls and three `*__deepset_critic__gated` presets. MLP-suffixed, SwiGLU, shared-encoder TMASAC, optional recurrent-control and segment names are unregistered; low-level classes/builders remain. Plain PPO/MAPPO remain. Canonical recurrent presets are MAT-IND/QCX LSTM and TMASAC LSTM/sLSTM. `mat_ind__no_attention` is removed; `tmasac_dec` disables actor attention. Canonical recurrent templates preserve baseline dimensions/FFNs and add temporal modules with common residuals/norms. RMAT temporal_hidden_dim decouples memory from token width through bias-free projections; actor-state critic adapter inputs use the temporal model hidden_dim; do not restore split FF or extra inter-module FFNs.
- Tools: `swarmbots/tools`; plotting: `swarmbots/plotting`. Matplotlib is optional/lazy; preserve caller backend and direct `plot_logs` export despite module-name collision. Aggregation: finite within-run interpolation, last finite duplicate-X, cutoff before interpolation, population std; seed counts vary with X.
- `docs/policy_parameters`: track compact snapshots/guides/comparisons only; verbose reports in ignored `generated/<scale>/`, diagrams ignored except README. `--refresh` updates snapshots, not tracked verbose reports.
- All MAT policies own `actor_encoder` and `critic_encoder`; config `encoder_config` describes the actor, `critic_encoder_config` the critic. NOP receives actor features. RMAT temporal state maps `actor`/`critic` to separate histories: rollout advances both, inference only actor, bootstrap only critic. Generic temporal-state utilities preserve this mapping through rollout/TBPTT. Old shared MAT checkpoints need retraining or manual migration. Use canonical TMASAC LSTM plus a `None` state-input override for a conditioning ablation.
- Architecture diagrams use nested `ComponentBlock` content in `tools/diagram_policy_architectures.py`; repetition and inclusive subtotals belong to the inset, additive parameter accounting to outer `Node` boxes. `tools/policy_diagram_layout.py` sizes actor/critic/NOP lanes and routes orthogonal connections around nodes and reserved labels. SVG/Pillow share geometry; Mermaid/Graphviz/JSON preserve nesting. Keep one-time projections/readouts outside repeated blocks.

## Learning and checkpoints

- SAC preset defaults are centralized in `presets/sac.py` with TMASAC as reference; explicit algorithm overrides win. Training examples reserve fresh output directories by scale/seed/unique ID and reject existing explicit directories; the lower-level `train` API still supports continuation.

- `examples/train_standalone_ppo.py` deliberately stays minimal and independent of `swarmbots.learn`. It uses only public observations and stores pre-tanh Gaussian samples: the squash Jacobian cancels in PPO ratios, avoiding inverse-tanh saturation issues.
- Torch environments/wrappers use SAME_STEP: returned observations are resets; terminals are `final_obs` selected by `_final_obs`. PPO truncation bootstrap uses terminals; recurrent PPO always needs TBPTT. Replay preserves reset masks/burn-in and physical actions. Swarms need an active unit. Observation buffers are reused; integer-indexed reset writes must assign back to source tensors.
- `base_policy.policy_inference_step` marks complete MAT/RMAT CUDA graph inference calls and snapshots returned tensors before bootstrap or subsequent actor calls reuse graph storage. Keep boundaries outside compiled submodules.
- `env_wrappers/torch_task_ep_stats_wrapper.py` accumulates progress rewards and preserves task-success presence masks through SAME_STEP terminal info and mixed scenarios.
- PPO uses fixed-step collection only and rejects dropout in its core policy; NOP auxiliary dropout remains separate. SPR is removed. gSDE schedules share `gsde_reset.py`; adapters inherit the trainer's mode and checkpoint recordings restore it from checkpoint `hyper_parameters`, written by `BaseAlgorithm.save`. Missing saved modes default to episode-only. Initialize per-agent noise before masked resets.
- Entropy regularization belongs to the learner: PPO uses its masked, joint-importance-weighted `mc_ent_coef`; SAC keeps temperature tuning. Distribution entropy extras/configs/commands and Gaussian quadrature are removed; ordinary diagnostics remain. Diagnostic masks belong to the cached parameter batch, which can differ from filtered action histograms; snapshot reusable environment masks and capture rollout diagnostics before replay updates replace that batch. Recurrent target batches reserve unused truncation successor slots; exclude them and padded final successors. NOP metric values stay detached on-device until aggregation; snapshot tensors before reusable compiled outputs are overwritten.
- Public distributions are guarded by `tests/test_release_metadata.py`; experimental families are excluded. On-policy defaults to `sign_magnitude_beta`, SAC to `predicted_std_gaussian`; override with `continuous_action_dist`. SAC needs pathwise/straight-through gradients: Gumbel SMB, including SMB checkpoint reconstruction. Multiple actor/target samples are independent.
- Squashed Gaussian Jacobians use the stable pre-tanh formula in `TanhBijector`; SAC supplies cached Gaussian samples, while PPO rollout/recomputation both use stored bounded actions.
- Encoder inputs preserve observation/action features before projection; raw-input LayerNorm and `normalize_obs_inputs` are removed because they erase scalar signals. Feature-wise observation wrappers and learned-feature normalization remain.
- Fixed-scale Deep Set construction preserves explicit `JointCriticConfig.encoder_config` / `head_config` structural controls, using top-level critic templates only when absent; mirrored configs must agree. Legacy baseline width arguments apply only without a fixed scale.
- Reconstruct matching task/architecture/distribution/NOP settings. Shape-changing switches: `mat_joint_obs_embedding` (default additive), `critic_independent_encoders` (TMASAC/TMATD3 default shared), `mappo_critic_context_in_elements` / `baseline_critic_context_in_elements` (default True). All Deep Set critics, including transformer Q readouts, use `nn_components/deep_set.py` interactions configured by `DeepSetInteractionConfig` / preset `deepset_interaction_config`; standalone baseline defaults come from `JointCriticConfig`. Changed layouts need manual checkpoint migration. NOP re-encoding must pass the agent mask to `encode_elements`: final per-agent features now depend on masked set messages.
- Deep Set interactions expand messages to 5D/4 with nonlinear pre/post-pool processing and bias-free compression. Gated blocks select expanded message features from local+global inputs before compression. Shared Deep Set critic encoders reuse `ActionConditionedEncoder` / `DeepSetEncoderLayer`, matching transformer embeddings, norms, residuals and FFNs; only the mixer differs. Reinitialize copied message/gate matrices as well as FFNs so depth does not start with identical communication weights. All Q heads use `build_q_network` (projection, two interactions, pooling, regressor). Twins own `encoder.network` and `q1/q2`; single DDPG keeps `JointQNetwork` in a ModuleList, with `.encoder.network` as trunk and `.network` as Q head. NOP uses pre-head tokens once (concatenated only for independent encoders). Canonical globals enter shared embeddings; `context_in_elements=False` retains raw globals only after Q-head pooling. Independent encoders remain low-level and never resize. Deep Set/transformer off-policy defaults use critic NOP and omit PopArt; flattened off-policy MLP rejects NOP. Fixed-slot MLP depends on agent count/order. MADDPG/MATD3 use shared-actor cooperative team objectives.
- TD3 delays use persistent update counts; critic NOP updates every step, actor NOP follows actor delay. SAC delay also gates temperature; targets keep their interval. Target smoothing retains original entropy log-probability. Deterministic policies have no action distribution.
- Recurrent TD3 keeps separate online/target actor states; feed-forward critics consume corresponding detached state (`td3_actor_state_critic_input_config=None` disables). Recurrent critics require recurrent TMATD3 actors and use replay history. Candidate branches must not overwrite executed-action history.
- Restore PPO LR controller and custom scheduler state/enabled flags/current values; schedulers require matching names/order. Adam LR alone can restart canceled warmup. Gaussian base std is persistent; legacy checkpoints retain constructor defaults.
- `logging_levels.py`: independent console/persistence profiles, default `minimal`/`full`. Filter after aggregation; retain scenario outcomes/step keys and CSV history/headers; restore compressed logs before append. Console keys: `"default"` follows profile, `None` all, `[]` silent.
- `train` saves/closes; `make_training` transfers close responsibility. Biasless PopArt needs its offset to preserve raw predictions; rotation conversion needs analytic sinc coefficients for zero-angle gradients.

## Benchmark and simulator

- Planar goal navigation is `SwarmBots-MoveToGoal-v0`: `mjw_move_to_goal_scenario.py` / `mjw_move_to_goal_runtime.py`, `MJWMoveToGoalScenario`, and `default_move_to_goal`. The goal config remains in `scenario_presets/move_to_goal_config.py`.
- Scenario spaces and serialized observation indices share hinge counts from `mjw_env/swarm/unit.py`, derived from the same joint definitions used to build robots.
- Protocol 0.1 allows cross-agent non-privileged actor inputs; privilege boundaries do not require decentralization. Observations are device-resident Torch tensors. Default pool seeds 42000–42049; evaluation seeds change sampling, not membership or held-out generalization.
- `MJWSwarmBotsVectorEnv` owns the raw active-agent count at `hidden_global_vars[..., 0]`; scenario spaces/runtimes describe only the suffix. Normalization indices shift scenario fields by one and leave the count raw. Deep Set Q critics consume this field without appending cardinality; former checkpoints need migration even when weight shapes match.
- Wall resets intentionally straddle the obstacle as implicit curriculum. Keep that distribution; already-solved milestones are latched without retroactive rewards.
- Fresh `as_benchmark_policy` per evaluation, on policy device: owns recurrent/action/distribution state, freezes normalization without changing training RMS, preserves module modes. Actor is shared; no concurrent training.
- Scenario-conditioned adapters need an explicit `scenario_id` for single-task evaluation; supplied observation IDs take precedence. Pad public globals to the training width before frozen transforms, never forward privileged fields.
- Scoring takes each lane's first episode, preserves lane order, requires `num_episodes <= num_envs`. Live exact-state recording recycles lanes, discards interrupted episodes on reset, closes environments, waits for MP4 writers. Checkpoint recording reuses `training._make_policy_env` without replay/optimizer allocation.
- All resets share `_reset_worlds`; positive `reset_settle_time` uses CPU-settled snapshots, zero disables. Seeded resets clear prefetch; pool changes invalidate ready/in-flight snapshots. FIFO reservations include ready/queued/in-flight: worker timing changes batching, never sampling order. Preserve shuffle RNG on repeated device setup; partial per-world reseeding must still reserve shared draws for worlds using the shared generator.
- Training adds seeded first-episode staggering in `make_training`, outside `_make_policy_env` so evaluation/recording retain full episodes. Explicit first-episode keys, including `None`, suppress the generated limits; use a separate RNG from policy initialization.
- Surface connector frames default; `legacy_connector_positioning=True` restores old spacing. Record it/connector distance; morphology/extents use resolved distance. Settling/frame/task-success corrections require reevaluation, not mixing old scores.
- Warp capture uses `data.qpos.device`, never Model.qpos. Task shapes share Dynamo caches: isolate processes or reset compiler state after closing environments, never silently reset callers' compiled policies.
- Scope runtime Warp work to PyTorch's current stream, including reset/deferred paths and GPU data initialization; capture physics separately on a capturable Warp stream. Model templates use separated padded slots, while the pool/reset paths supply actual assemblies. Payload row spacing records a footprint-aware minimum; reset sampling adds float32 clearance from each row's actual origin and span, since spawn distributions can be unbounded.

- Pool generation in `mjw_homogeneous_swarm.py` grounds active assemblies analytically via `unit.get_unit_rest_min_z`, including noncolliding connector tips. This assumes zero reset hinge angles and yaw-only runtime rotation. `z_pos=None` uses `ground_clearance`; numeric `z_pos` retains the old height plus `swarm.initial_z_offset` in the shared reset sampler.
