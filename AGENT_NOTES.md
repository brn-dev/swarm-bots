# Agent Notes

Keep durable architecture notes and costly gotchas; omit implementation history and settings available in source.

## Codebase Map

- `swarmbots/mj_env`: CPU MuJoCo; `swarmbots/mjw_env`: batched GPU MJWarp; `swarmbots/learn`: policies, algorithms, rollout/replay, wrappers, distributions, checkpointing, logging, world models.
- `scripts/` holds entry points; `.ref/` holds xLSTM, MAT, and SB3 references. Shared experiment setup: `experiments/mjw_experiment_common.py`, `experiments/external_benchmarks/benchmark_experiment_common.py`, and `experiments/tmasac_experiment_common.py`.
- Thesis launch settings live in `experiments/thesis_experiment_common.py`; PPO rollout ablations use `run_thesis_ppo_experiment(...)`. MAPPO deliberately uses MAT-independent with agent attention disabled to match the comparisons' MLP structure.
- Thesis styles, source groups, and separate baseline/ablation comparisons live in `experiments/thesis_plot_common.py`; summaries use `experiments/thesis_result_summary.py` with the same sources and 100M-step cutoff. Direct plot calls need style overrides; renamed groups need algorithm mappings. `experiments/plot_all_thesis.py` runs thesis plotters sequentially, continues after failures, and supports `--dry-run`.
- Plot markers average finite, cutoff-filtered samples in centered 2%-range windows; they do not alter curves or statistics. `GROUP_MARKER_COUNT`/`GROUP_MARKER_SIZE` control overlays; marker dimensions follow source lines and enlarged fonts. Final summaries report first success-EMA threshold crossings (25/50/75/90/95/98%), reached-run counts, and population mean/std; unreached thresholds have null statistics.
- Distribution grids use suite-local `scripts/<distribution>/common.py` adapters; parent common code owns settings. Append non-default distributions to `variant_name` to avoid collisions. Post-thesis launch/reporting code is in `experiments/post_thesis_action_dist{,_plot}_common.py`; `ALGORITHM_VARIANTS` drives coverage and `{algorithm}_{distribution}` group names. MAT baselines use sign-magnitude Beta; TMASAC uses its Gumbel variant.

## Autoreset And Observations

- Learning uses Gymnasium `AutoresetMode.SAME_STEP`; the `NEXT_STEP` wording in `AGENTS.md` is stale. Consult `gymnasium_autoreset.md` and `worker_pool_async_vector_env.py` before reset/rollout changes. Done steps return reset observations; terminal observations are `infos["final_obs"]` selected by `infos["_final_obs"]`, with terminal statistics possibly in `final_info`.
- Observation wrappers must also transform `final_obs`, without updating normalization RMS from it. Agent shuffling uses the old permutation for terminal observations and the new one for reset observations. Transition observations preserve terminal features and zero reset features.
- Environment/shared-memory/GPU observation buffers and `copy=False` conversions can mutate on the next environment call.
- Learn observations require `local_obs`, `global_obs`, `hidden_local_vars`, `hidden_global_vars`; `agent_mask` is optional. Layout changes require normalization, adapter, replay, `build_obs_indices(...)`, and world-model target updates.
- Wrapper order: learn conversion → optional shuffle → episode statistics → progress statistics → observation normalization → optional transition observations → reward normalization. Skip reward normalization with PopArt.

## Rollout, Replay, And SAC

- PPO chunks can start mid-episode: use `PPOEpisodeSegment.is_true_episode_start`. `PPORolloutState` owns recurrence; terminal bootstrapping evaluates `final_obs` without committing state, and the next reset observation consumes the done mask. MAT/RMAT TBPTT uses env-major rows, one initial state per row, and time-masked padding/world-model losses.
- `OffPolicyReplayBuffer` is a per-env ring with `capacity + 1` observation slots; reset observations stay in-stream, terminal observations in an indexed compact pool. Continue nonempty replay with its returned `OffPolicyRolloutState`; an independent env reset breaks slot continuity. Random recurrent collection must still advance policy state.
- Replay stores physical actions; condition next observations on sampled `actions` (`next_previous_actions` does not exist). Recurrent replay uses sparse state checkpoints and cached starts. Ordinary segments cannot cross episodes; recurrent SAC streams can, resetting via `episode_start_mask`. Burn-in supplies context only.
- `SAC` handles feed-forward policies; `RecurrentSAC` handles recurrent/segment policies. Checkpoints omit replay/rollout state: loading clears and refills replay while retaining counters and optimizer schedules. Strict loading canonicalizes `._orig_mod.` paths for compiled/uncompiled continuation; ambiguous keys remain errors.
- SAC distributions must register pathwise or straight-through gradients. Rollout/target Q use `sample()`; actor updates use `rsample()` via `use_rsample=True`. Entropy log-probabilities/targets average agents; distribution auxiliary losses are separate per-row sums. Continuous SAC requires `Box`.
- `actor_action_samples`/`target_action_samples` default to 1; `action_sample_strategy` is `iid` or `stratified`. Multiple samples add a training-only leading candidate axis: clip twin Q before averaging. `action_sampling.py` stratifies Bernstein/RQS uniforms independently per marginal; other distributions remain iid. Multiple candidates do not support gSDE.
- `BaseSACPolicy.action_log_prob(...)` handles both single and multiple samples through `num_action_samples`/`action_sample_strategy`. Recurrent policies use a reset state for this API; sequence methods accept replay state explicitly. TMASAC encodes once before expanding actor candidates, with independent QCX trajectories and a separate compiled multi-sample tail; average candidate auxiliary losses before agent reductions. Recurrent targets assemble shifted/final/truncation latents before sampling. Policies own candidate critic evaluation: `q_values_samples(...)` batches feed-forward Q inputs, and `q_values_sequence(..., num_action_samples=...)` handles stateless, shared, and action-conditioned recurrent critics. RecurrentSAC advances executed replay history once per timestep. Candidate critics flatten candidate/batch axes together and repeat the initial temporal state in the same candidate-major order; each branch starts from that replay history. NOP/actor-state features keep ordinary batch/time shapes; candidate critic forwards return no NOP latents, and action-conditioned candidates have no common next state. Configure encoder-only compiled entry points for every action sequence length so both sample modes work; single-sample calls retain their end-to-end compiled paths.
- Segment TMASAC flattens batch/time only inside observation and critic encoders. Restore the original leading shape before sampling, including an explicit length-one time axis, so cached distribution parameters and auxiliary entropy masks agree.
- gSDE retains standard-normal temporal noise and applies current std at sampling. Agent noise is the third axis from the end (`[..., agents, latent, actions]`), including sequence batches. Preserve `OffPolicyRolloutState.gsde_noise_state`; validate with `resolve_gsde_reset_mode(...)`.

## Policies And World Models

- `MATQCBasePolicy` shares QCS/QCX/QCC plumbing; QCC extends QCS with its decoder, QCX attends query-to-context only, and `MATIndPolicy` is decoderless. `MATDecPolicy` separates critic/actor encoders; its actor sees local/global observations without agent attention, and `act()` skips the centralized critic.
- `MATOrigPolicy` requires an active-agent prefix and shifted previous-agent actions. QCS/QCC/QCX allow arbitrary inactive positions with at least one active agent per row; `assume_agent_mask_is_active_prefix=True` enables the cheaper path.
- Recurrent cores must honor reset masks using overwrite/selection: multiplying by zero cannot clear NaN/Inf.
- Shared TMASAC encoders are critic-owned with detached actor inputs; reuse the learning-sequence shared forward for actor, critic, and shared-latent NOP. Keep compiled shared encoder and downstream actor in separate AOTAutograd graphs: detach does not permit independent backwards through one compiled graph. Shared NOP includes the first action in its transition rollout.
- Shared variants live in `tmasac_experiment_common.py`: two-layer width-256 shared MAT/RMAT, one-layer downstream encoders; shared sLSTM keeps downstream encoders feed-forward and omits separate actor-state critic summaries. The thesis `slstm_two_small_actor_state_critic_recurrent_skip` ablation changes only `rmat_temporal_residual`.
- `NextObsPredWrapper`/`SPRWrapper` must delegate sampling, temporal-state APIs, and `after_optimizer_step()`. World-model losses use `wm_actions`, not PPO current-step actions; SPR does not support RMAT. Global prediction uses explicit scalar/rot6d indices, pools valid active-agent latents, and excludes rows without valid next-active agents.

## Action Distributions

- Register continuous construction/actor-gradient capabilities in `hybrid_action_dist.py`. Action heads must be `nn.Linear` even at equal widths to honor initialization gain. Mutable scalars must be tensors/buffers; sticky distributions keep `requires_previous_actions()` stable through annealing.
- Bernstein/RQS share `BoundedQuantileActionDist`; zero-initialized heads give uniform `[-1, 1]`, deterministic evaluation approximates the density mode. SAC computes actions/log-Jacobians from the same uniform sample without inversion. PPO uses `get_on_policy_actions_with_log_probs(...)` and recomputes likelihood from stored float32 actions to preserve unit unchanged-policy ratios.
- Inverse likelihood uses Bernstein bisection or RQS analytic inversion plus differentiable Newton refinement; RQS solves from the nearer endpoint to avoid cancellation. Derive increments/bin sizes from exact endpoint-fixed coefficients/knots for float32 consistency. On-policy entropy uses a fresh uniform Jacobian sample; skip it at zero coefficient.
- RQS learns endpoint derivatives by default (uniform slopes are 2). Older fixed-boundary checkpoints need `fixed_boundary_derivatives=True`; learned boundaries add two head outputs per action.
- `TernarySignMagnitudeBetaActionDist` has negative/positive Beta branches and a zero point mass: exact categorical rollout, hard straight-through Gumbel SAC, categorical `log_prob(0)`. Legacy sign-magnitude negative branches use `action = -1 + U`, inverse `U = action + 1`; switching to `-U` requires migration.

## Scenarios, MJW, And Evaluation

- `SwarmBotsEnv` delegates cadence/reset baselines/progress to scenarios and must reseed `scenario.rng` on seeded reset. MJW scenario behavior belongs in runtime classes via `scenario.build_runtime_metadata(...)`; keep `MJWModelMetadata` generic.
- `MultiScenarioVectorEnv` combines homogeneous SAME_STEP groups: local observations, masks, and actions must match; other fields are padded. Preserve `scenario_id` through terminal/replay/recurrent/successor paths. External MaMuJoCo/PettingZoo and batched VMAS adapters live in `swarmbots/external_benchmark_envs`, exposing actor `local_obs`, centralized `hidden_global_vars`, and agent-mean rewards.
- `MJWSwarmBotsVectorEnv` uses one MJWarp model with batched GPU data; resets are direct, one-shot settled, or background CPU-settled snapshots. Keep hot paths fixed-shape, kernelized, allocation-light; no CUDA `nonzero()`/variable-length connector indexing. Reuse scratch buffers; Warp indices are `int32`. Fixed-shape Torch operations compile on CUDA; keep Warp launches/variable-cardinality bookkeeping outside graphs.
- Nonfinite `qpos`/`qvel` terminates/resets that world, masks terminal observations on-device, and warns once per run. Connection counts credit each new edge to both units, exclude reset preconnections, and include reconnections. Emit `successful_connections_per_unit_*` population moments before reset clears counters; evaluation pools episode-unit moments, including outcome-conditioned groups (null if empty).
- Overlays use `BaseScenario.add_render_geoms(scene)` after `Renderer.update_scene()`. Shared-renderer MJW recording above 640×480 needs `ensure_mujoco_offscreen_framebuffer(...)`.
- Frozen milestone evaluation uses a persistent second env: matched stochastic/deterministic seeded settled resets, frozen normalization, isolated Torch/CUDA RNG and distribution state. Metrics go only to `eval_log.csv`; videos use deterministic passes. Defaults: 256 lanes, one episode/lane, 25/50/75/90/95/100% milestones; lane/episode counts are configurable.
- `run_experiment(additional_timesteps=...)` makes evaluation/recording schedules relative to the loaded counter while the learner gets an absolute final counter. `evaluation_scenario_kwargs` can separate training/evaluation pools. Disconnected fine-tuning launchers disable videos/live recording because cluster EGL is unreliable; scalar evaluation remains enabled.
- Connector-free policies remove connector dimensions and send physical connectors `-1`. Migration retains actuator heads and trims trailing connector columns in critic/NOP inputs. Rebuild the reduced interface before strict loading/recording; clamping a full-action policy is a different ablation.
- Morphology evaluation starts at `experiments/evaluate_thesis_mjw_unseen_morphologies.py`; disconnected variants set `unconnected_prob=1.0` while preserving pre-connected placement generation. `_no_connections.py` also clamps connectors and uses separate outputs. Prefer latest final checkpoints, otherwise the best snapshot with greatest sidecar timestep. Default 512 lanes accept only each lane's first episode to avoid early-termination bias. Preserve source critic memory features; canonicalize legacy compile keys and reset compiler caches between morphology sizes.
- `experiments/thesis_mjw_po_wall_disconnected_finetune/evaluate_tmasac_50m.py` coordinates resumable medium/hard × connector-enabled/actuator-only evaluation and pooled `global_summary.json`. Evaluation topology seeds start at 1,000,000, disjoint from training's 42,000–42,049.

## Runtime Conventions

- Put temporary files in repository-root `.tmp/`; use the existing `.venv` directly and `uv` only for dependency management.
- In the managed Windows sandbox, point `TEMP`, `TMP`, and `TORCHINDUCTOR_CACHE_DIR` at pre-created repo-local directories under `.tmp/` in the same PowerShell process before invoking pytest. The Inductor override is required for real CUDA `torch.compile` tests; otherwise compilation fails with `PermissionError` under the user temp directory.
- CPython 3.13 gives `tempfile.mkdtemp()` directories a Windows `0o700` ACL, which excludes the sandbox identity even below a writable repo directory. W&B creates two such directories at import and otherwise prints `PermissionError` traces during interpreter shutdown. For clean sandbox test runs, put a temporary `sitecustomize.py` on `PYTHONPATH` that saves `os.mkdir` and wraps it so Windows `mode == 0o700` is passed to the original function as `0o777` (other modes unchanged); with `TEMP`/`TMP` redirected as above, the directories then inherit the sandbox-accessible parent ACL. Keep this workaround sandbox-local, since it deliberately weakens temporary-directory isolation.
- Record durable solutions to environment, sandbox, and toolchain failures in this file, including the symptom, cause, and concrete workaround, so later agents do not rediscover them.
- Hyperparameters are live attributes; changing config dataclasses after initialization has no effect. Canonicalize devices with `as_device(...)`: `cuda` and `cuda:0` compare unequal.
- MJ/MJW default to continuous connector actions; legacy binary runs require `continuous_connector_actions=False`. Headless Linux defaults unset `MUJOCO_GL` to `egl`.
- `ParameterLearnMode.PER_FEATURE` needs a feature count; generic code uses `make_activation(...)`. Initialization gains: hidden/projection/transformer FF = 1.0; action/value/prediction outputs = 0.01.
